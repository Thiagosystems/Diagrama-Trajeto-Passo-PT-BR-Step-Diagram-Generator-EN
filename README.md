# Diagrama-Trajeto-Passo-PT-BR-Step-Diagram-Generator-EN
Diagrama trajeto-passo Gera o diagrama trajeto-passo a partir de uma sequência como "A+ B+ A- B-", com blocos simultâneos entre parênteses. Desenha em ASCII e SVG, monta a tabela de movimentos e avisa quando há risco de sinal bloqueado no circuito.
